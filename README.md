# Retro Drifters

A 2D top-down racing game I built in Python using Pygame, as my Computer Science NEA.

## What's in it

- 6 tracks I designed myself: Oval Dunes, Figure-8 Rainway, Hairpin Glacier, Sprint Circuit, Maze Harbor, and Mixed Mayhem
- 5 cars you can buy and upgrade with coins earned in races
- Weather that actually affects the driving — rain makes you slide, fog kills your visibility, sandstorms slow you down
- Moving, rotating, and pulsing obstacles you can smash at high speed
- AI opponents on 3 difficulties that actually take racing lines
- Power-ups: nitro, repair, shield, speed boost, magnet
- Per-user saves so each account has its own progress and best times

## Running it

You'll need Python 3.10+ and Pygame.

    pip install pygame
    python ultimate_racing_2d.py

## Controls

WASD or arrow keys to drive, Shift for nitro, Esc to pause.

## Files

- ultimate_racing_2d.py — the game
- login_system.py — accounts and login
- assets/ — sprites and art
